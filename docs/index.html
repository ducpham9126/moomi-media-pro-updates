Cập nhật ứng dụng

Các bản 1.3.1 và mới hơn đã phát hành trên GitHub dùng nguồn cập nhật mới. Bấm biểu tượng cập nhật ở góc trên bên phải ứng dụng để kiểm tra.

Nếu bạn đang dùng 1.0.00, 1.0.02 hoặc 1.0.03, cần cài thủ công một lần để chuyển khóa ký:

  1. Tải gói ứng dụng mới nhất ở nút phía trên.
  2. Thoát Moomi bằng Command + Q, rồi giải nén ZIP.
  3. Chép Moomi Media Pro.app vào Applications và thay bản cũ.

Dữ liệu bản quyền và ảnh gốc được giữ nguyên. Các bản cũ dùng khóa ký cũ đã ngừng phân phối.
